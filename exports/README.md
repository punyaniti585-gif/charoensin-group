# ชุดส่งมอบ HTML สำหรับนักศึกษา

ส่งออกวันที่ 17 พฤศจิกายน 2569 จากหน้าเว็บสาธารณะ ขณะไม่เข้าสู่ระบบ WordPress

## ใช้งาน

- ดาวน์โหลดไฟล์ `<slug>.html` เพื่อดูหน้าแบบไฟล์เดียว (CSS/JavaScript ที่ดาวน์โหลดได้ถูกรวมไว้ในไฟล์) ภาพ วิดีโอ ฟอนต์ และ API บางส่วนยังใช้เว็บเดิม ต้องมีอินเทอร์เน็ต
- แนะนำดาวน์โหลด `<slug>.zip` แล้วแตกไฟล์ ใช้ `index.html` พร้อมโฟลเดอร์ `assets` เพื่อแก้ HTML/CSS/JS แยกไฟล์
- เปิดผ่าน local HTTP server เช่น VS Code Live Server หรือ `python3 -m http.server 8000` อย่าใช้ file:// หาก Script ต้องการ HTTP
- `wordpress-content.html` คือ post_content ต้นฉบับ เหมาะใช้แก้เนื้อหา กลับเข้า WordPress ต้องใช้ตัวแก้ไข/Template เดิม
- บางหน้า post_content ว่างเพราะใช้ Template; ใช้ index.html เป็น snapshot และดู metadata.json ไม่ใช่หน้าว่างเสียหาย
- หน้า Elementor ใช้ HTML ที่แสดงผลจริง ไม่รวมการตั้งค่า editor หรือแบบฟอร์มส่วนหลังบ้าน
- `metadata.json` และ `asset-manifest.json` บันทึก URL ต้นทาง สถานะไฟล์ และข้อจำกัด

## ข้อจำกัด

นี่คือ snapshot ส่วนแสดงผล ไม่ใช่สำรองระบบ WordPress/PHP/ฐานข้อมูล ไม่รวมรายการผู้สมัครงานหรือข้อมูลหลังบ้าน
รูป/วิดีโอ/ฟอนต์ส่วนใหญ่ยังอ้างอิงเว็บไซต์เดิม CSS @import และการโหลดทรัพยากรเพิ่มจาก Script อาจต้องใช้อินเทอร์เน็ต
แบบฟอร์ม สมัครงาน ค้นหา ข่าวสาร และ AJAX/REST API อาจยังต้องใช้ WordPress และ nonce เดิมอาจหมดอายุ ห้ามถือว่าทำงานแบบ standalone ครบทุกระบบ
อย่าทดลองส่งแบบฟอร์มจริงขณะทดสอบหน้าตัวอย่างโดยไม่ได้รับอนุญาต
ไลบรารี WordPress/ปลั๊กอิน/ฟอนต์ยังมีเงื่อนไขสิทธิ์ของเจ้าของเดิม เก็บชื่อและแหล่งอ้างอิงไว้
HTML ที่รวม Script เป็น data URL อาจติดข้อจำกัด CSP/โมดูล ให้ใช้ ZIP และไฟล์แยกเมื่อพัฒนาจริง
หากต้องการนำไป React/Astro ต้องแยก component และการเชื่อม API เพิ่ม ไม่ใช่เปลี่ยนนามสกุลไฟล์
