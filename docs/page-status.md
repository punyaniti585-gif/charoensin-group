## อ่านสถานะก่อนรับงาน

- **มีลิงก์แล้ว · รอตรวจรับ**: เจ้าของงานส่ง URL มาแล้ว ให้ตรวจและแก้หน้าเดิมก่อน ไม่สร้างซ้ำ ยังไม่ได้รับรองว่าเสร็จครบ
- **ยังไม่มีลิงก์ · รอตรวจสอบ**: ยังไม่มี URL ในข้อมูลส่งมอบ ไม่ได้หมายความว่าหน้านั้นไม่มีอยู่ ต้องตรวจ WordPress และเนื้อหาในหน้ารวมก่อน
- **ยังไม่ได้ทำ**: ใช้หลังตรวจแล้วว่าต้องสร้างใหม่
- **รอผู้บริหารตรวจสอบ**: ส่งลิงก์ให้ผู้บริหารแล้ว รอความคิดเห็นก่อนแก้ไขเพิ่มเติม
- **กำลังทำ**: ระบุผู้รับผิดชอบและ Issue ก่อนเริ่ม
- **เสร็จแล้ว**: ใช้หลังตรวจรับ พร้อมวันที่และผู้ตรวจ

หมวดเมนูอาจเป็นเพียงหัวข้อหรือส่วนในหน้ารวม ไม่จำเป็นต้องสร้างหน้าแยกทุกแถว ผู้รับผิดชอบและไฟล์ต้นฉบับยังไม่ได้ระบุ

## ขั้นตอนส่งต่องาน

1. เปิดทะเบียนนี้และค้นหาหน้าเดิมใน WordPress รวมถึงส่วนในหน้ารวม ก่อนเริ่มสร้างหน้า
2. เปิด Issue โดยใช้รหัสหน้าเป็นชื่อ เช่น `[02.02] พันธกิจ` แล้วระบุผู้รับผิดชอบ URL เดิม งานที่เหลือ และเกณฑ์ตรวจรับ
3. บันทึก WordPress Page ID, ตัวแก้ไขที่ใช้, template และไฟล์ต้นฉบับลงใน Issue ห้ามใส่รหัสผ่าน โทเคน หรือข้อมูลส่วนบุคคล
4. ทำงานบน branch ของงาน และส่ง Pull Request อ้างอิง Issue
5. อัปเดตสถานะในทะเบียนนี้และ `../data/sitemap.json` ให้ตรงกัน เมื่อมีการเปลี่ยนแปลง
6. ก่อนปิดงาน ตรวจ desktop/mobile ลิงก์เมนู เนื้อหา และฟังก์ชันที่เกี่ยวข้อง แล้วบันทึกผู้ตรวจและวันที่ตรวจรับ

URL เป็นข้อมูลอ้างอิงหน้าเว็บ ไม่ใช่การสำรองโค้ด WordPress หรือไฟล์สื่อ ไฟล์นี้ยังไม่ได้ส่งออกโค้ดหรือเนื้อหาหน้าเว็บ
