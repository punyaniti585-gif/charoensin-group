# charoensin-group

เอกสารส่งต่องานเว็บไซต์ https://csgok.sfinsulations.com/ สำหรับนักศึกษาและผู้พัฒนาที่รับงานต่อ

## เริ่มที่นี่

**นักศึกษาอ่านก่อนเริ่มงาน:** [คู่มืออัปเดตงานรายวันและแบบฟอร์ม](docs/student-update-guide.md)


1. อ่าน [ทะเบียนหน้าเว็บและสถานะครบ 8 เมนู](docs/page-status.md)
2. ตรวจ URL และหน้าเดิมก่อนสร้างงานใหม่ หน้าไม่มีลิงก์ต้องตรวจสอบก่อน ห้ามตีความว่าไม่มีหน้าอยู่แล้ว
3. เปิด Issue ระบุรหัสหน้า ผู้รับผิดชอบ และงานที่เหลือ ก่อนเริ่มแก้ไข

## ไฟล์อ้างอิง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| [docs/page-status.md](docs/page-status.md) | โครงสร้างเมนูทุกระดับ ลิงก์ที่ได้รับ และงานที่ต้องตรวจต่อ |
| [data/sitemap.json](data/sitemap.json) | ข้อมูลโครงสร้างเมนูและสถานะแบบ JSON สำหรับระบบหรือ AI |

มีลิงก์จากเจ้าของงาน 9 หน้า: 8 หน้าผูกกับโครงสร้างเมนู และนโยบาย AI อีก 1 หน้ารอยืนยันตำแหน่ง หน้าที่มีลิงก์อยู่ระหว่างรอตรวจรับ โดยหน้ามูลนิธิส่งให้ผู้บริหารตรวจสอบแล้ว ส่วนรายการไม่มีลิงก์อยู่ในสถานะรอตรวจสอบ

มีไฟล์ส่งออกส่วนแสดงผล HTML พร้อม CSS/JavaScript และเนื้อหาต้นฉบับที่เกี่ยวข้องแล้วใน exports (17 พฤศจิกายน 2569) ไม่ใช่สำรองระบบ WordPress/PHP/ฐานข้อมูลทั้งหมด ภาพ วิดีโอ และฟังก์ชัน API บางส่วนยังอ้างอิงเว็บเดิม ไม่มีการเปลี่ยนเมนูบนเว็บไซต์จริง
