# คู่มืออัตลักษณ์องค์กร (CI Brand Guidelines) - กลุ่มบริษัทเจริญสิน (Charoensin Group)

เอกสารมาตรฐานด้านการออกแบบและแนวทางการพัฒนาเว็บไซต์สำหรับ **กลุ่มบริษัทเจริญสิน (Charoensin Group - CSG)** อ้างอิงตามอัตลักษณ์องค์กร ประวัติศาสตร์กว่า 90 ปี (ก่อตั้ง พ.ศ. 2475) และข้อมูลโครงสร้างธุรกิจ

---

## 1. พาเลตต์สีองค์กร (Corporate Color Palette)

| ชื่อสีเชิงความหมาย | รหัสสี (HEX) | การใช้งาน |
|---|---|---|
| **CSG Gold (Primary)** | `#B39B6B` | สีทองหลักของแบรนด์: เส้นขอบไฮไลต์, ปุ่มหลัก, ไอคอนสำคัญ, หัวข้อย่อย |
| **CSG Gold Dark (Deep Bronze)** | `#6B5A3A` | สีทองเข้ม/บรอนซ์: สถานะ Hover, ข้อความเน้นเข้ม, พื้นหลังการ์ดระดับพรีเมียม |
| **CSG Gold Light (Champagne)** | `#D9CBAA` | สีทองอ่อน/แชมเปญ: เส้นขอบบาง, แถบประดับ, พื้นหลังโปร่งแสง |
| **CSG Cream (Warm Surface)** | `#F2EFE9` | สีครีมอุ่น: พื้นหลังสลับเซกชัน (Alternative Section Background), การ์ดข้อมูล |
| **CSG Dark (Charcoal Text)** | `#1F1F1F` | สีเทาดำเข้ม: ตัวอักษรเนื้อหาหลัก (Body text), หัวข้อที่ต้องการคอนทราสต์ชัดเจน |
| **CSG White** | `#FFFFFF` | สีขาวบริสุทธิ์: พื้นหลังหลัก, ตัวอักษรบนพื้นสีเข้ม |

## 2. ฟอนต์และระบบตัวอักษร (Typography)

| ฟอนต์ | น้ำหนัก (Weights) | วัตถุประสงค์การใช้งาน |
|---|---|---|
| **Kanit** | 300 (Light), 400 (Regular) | หัวข้อภาษาไทย (Thai Headings, Titles, Subtitles) ให้ความรู้สึกร่วมสมัย มีพลัง และภูมิฐาน |
| **Sarabun** | 400 (Regular) | เนื้อหาภาษาไทย (Thai Body Text, Paragraphs, Lists) เพื่อความสบายตาและการอ่านที่ชัดเจน |
| **Playfair Display** | 400, 600, 700 (Serif) | หัวข้อภาษาอังกฤษระดับพรีเมียม (English Display / Brand Heritage Headings) สะท้อนความคลาสสิกและประวัติศาสตร์ยาวนาน |
| **Inter** | 300, 400, 500, 600 | ข้อมูลสากล ตัวเลขสถิติ และส่วนติดต่อผู้ใช้ (UI / Data Metrics / Numbers) |

## 3. หลักการเคลื่อนไหว (Motion Principles)

- **นุ่มนวล ช้า สง่า (Smooth, Slow, Elegant & Dignified)**:
  - แอนิเมชันต้องสะท้อนภาพลักษณ์กลุ่มบริษัทข้ามอุตสาหกรรม (Conglomerate) ที่มั่นคง ยั่งยืน ไม่หวือหวาหรือเร็วเกินไป
  - การเลื่อนปรากฏ (FadeUp): ใช้ระยะการเคลื่อนที่สั้น (เช่น 24px - 40px) พร้อมระยะเวลา 0.8 - 1.2 วินาที และ Easing แบบนุ่มนวล `[0.16, 1, 0.3, 1]`
  - ตัวเลขนับขึ้น (CountUp): เหมาะสำหรับตัวเลขสถิติสำคัญ (เช่น 80 ปี, 16,890 ราย, 1,390 คน, 99.90%) ใช้เวลาแสดงผล 2.0 - 2.5 วินาที
  - **การเข้าถึง (Accessibility / prefers-reduced-motion)**: ตรวจสอบและลดการเคลื่อนไหวอัตโนมัติเมื่อผู้ใช้เปิดโหมดลดการเคลื่อนไหว โดยเปลี่ยนเป็นการแสดงผลทันทีหรือเพียงแค่เปลี่ยนความทึบแสง (Opacity) อย่างนุ่มนวล

---

## 4. โครงสร้างกลุ่มธุรกิจ (Business Pillars)
1. **อสังหาริมทรัพย์ (Real Estate)**: บริษัท เจริญสิน แอสเสท จำกัด, บริษัท เจริญสิน พัฒนา จำกัด
2. **ผลิตหนังและรองเท้า (Leather & Footwear)**: บริษัท ซีพีแอล กรุ๊ป จำกัด (มหาชน), บริษัท แมนวูด อินเตอร์เทรด จำกัด
3. **สิ่งทอ (Non-woven Textiles)**: บริษัท ทีทีเอ็น นันวูเว่น โซลูชั่น จำกัด, บริษัท ซงเม่า นันวูเว่น จำกัด, บริษัท เอฟแอนด์ที นันวูเว่น โซลูชั่น จำกัด, บริษัท เอชอาร์ที นันวูเว่น จำกัด
4. **เคมีภัณฑ์ (Chemical & Materials)**: บริษัท แอ็พพลาย ดีบี จำกัด (มหาชน), บริษัท อีเกิ้ล เคมีคอล อินดัสตรี จำกัด, บริษัท ซี เอส รับเบอร์ อินดัสทรี่ จำกัด, บริษัท ซีเอส ยูนิเทล เทคโนโลยี จำกัด, บริษัท ซี เอส มิตซูฟุกุ อิลาสโตเมอร์ จำกัด, บริษัท ซีเอสเจ รับเบอร์ชีท จำกัด
5. **ธุรกิจอื่นๆ (Other Ventures)**: บริษัท เจริญสิน แคปปิตอล จำกัด, บริษัท ไทย ไวร์ริ่ง ซิสเต็ม จำกัด, บริษัท แสงบูรพา แพลนเทชั่น จำกัด, บริษัท ไฟน์ ฟู้ด แฟกเตอร์ จำกัด, บริษัท สมาร์ท เซนส์ อินดัสเตรียล ดีไซน์ จำกัด, บริษัท นาว เอนด์ออฟเวสท์ จำกัด, บริษัท รักษาความปลอดภัย บี-เบสท์ เซอร์วิส จำกัด
6. **มูลนิธิร่วมเจริญสิน (Charity & Sustainability)**

## 5. มาตรฐานการใช้ภาพและป้ายกำกับสื่อ AI (Imagery & AI Attribution)

- **ความโปร่งใสและธรรมาภิบาลข้อมูล (Transparency & Governance)**:
  - ภาพทิวทัศน์หรือภาพประกอบแนวคิด (Conceptual Graphics) ที่สร้างขึ้นด้วย Generative AI (เช่น ภาพปก Hero Cover ท้องฟ้าจรดผืนน้ำ) จะต้องแสดงป้ายกำกับข้อความขนาดเล็ก `"ภาพ AI"` (AI-Generated Image Badge) บริเวณมุมขวาล่างขององค์ประกอบภาพ
  - ป้ายกำกับต้องออกแบบด้วยโทนสีสุภาพ โปร่งแสง กลมกลืนกับดีไซน์ แต่ยังคงมองเห็นได้อย่างชัดเจนตามหลักการกำกับดูแลกิจการที่ดี

## 6. โครงสร้าง Editorial Bento Grid (Flagship Bento)

- การจัดวางการ์ดธุรกิจที่ขับเคลื่อนอนาคต (Businesses Driving the Future) ใช้รูปแบบ **Editorial Bento Grid**:
  - การ์ดธุรกิจเรือธงระดับบริษัทจดทะเบียนในตลาดหลักทรัพย์และอุตสาหกรรมหลัก ได้แก่ **ADB (แอ๊พพลาย ดีบี)** และ **CPL (ซีพีแอล กรุ๊ป)** จะมีขนาดใหญ่และโดดเด่นที่สุด (2x2 หรือพื้นที่ขนาดใหญ่)
  - ตามด้วยการ์ดกลุ่มนวัตกรรมและการพัฒนาสังคม ได้แก่ **TTN (ทีทีเอ็น นันวูเว่น)**, **TWS (ทีดับบลิวเอส)** และ **มูลนิธิร่วมเจริญสิน**
  - แสดงปุ่มวิดีโอพรีวิวแบบนุ่มนวล พร้อมแสดงโลโก้บริษัทจริงและป้ายสถานะลิงก์ที่รอยืนยันตามทะเบียนงาน

## 7. มาตรฐานปุ่มกดและการนำทาง (Buttons & Actions)

- **ปุ่มหลัก (Primary Action Button)**:
  - พื้นหลังใช้สี **Deep Bronze (`#6B5A3A`)**
  - ตัวหนังสือสีขาวบริสุทธิ์ (`#FFFFFF`) ฟอนต์ `Kanit` หรือ `Sarabun`
  - สถานะ Hover: ปรับเป็นสี **Primary Gold (`#B39B6B`)** หรือเพิ่มความสว่างนุ่มนวล พร้อมเงาแบบพรีเมียม
- **ปุ่มรอง (Secondary / Ghost Button)**:
  - เส้นขอบบางสี Primary Gold (`#B39B6B`) หรือสีครีมอุ่น (`#F2EFE9`) ตัวหนังสือสีทองหรือสีเข้ม


---

## 8. มาตรฐานการแสดงโลโก้บริษัทในเครือ (Affiliate Logos - CI ข้อ 5)

- **การจัดวาง (Logo Wall / Grid)**:
  - จัดวางบนการ์ดพื้นหลัง **Soft Beige (`#D9CBAA/20` ถึง `#D9CBAA/30`)** ขอบมนเล็กน้อย (Rounded-xl)
  - **CSS Filter Monochromatic Effect**:
    - สถานะปกติ (Default): กรองสีโลโก้ให้เป็นโทนสีเดียว **Deep Bronze (`#6B5A3A`)** ผ่าน CSS Filter (`grayscale(100%) sepia(80%) hue-rotate(5deg) brightness(0.65) contrast(1.2)`) เพื่อสร้างเอกภาพและความสง่างาม ไม่แย่งสายตา
    - สถานะชี้เมาส์ (Hover): ปลดฟิลเตอร์กลับเป็นสีจริงของแต่ละแบรนด์อย่างนุ่มนวล (`filter: none`) พร้อมยกการ์ดขึ้นเล็กน้อย

## 9. มาตรฐานคำขวัญองค์กร (Taglines & Brand Heritage)

- **Tagline ภาษาอังกฤษ**: *"Building value through trust, driving growth across generations."* และ *"Today's Progress. Tomorrow's Greatness."*
- **Tagline ภาษาไทย**: *"สร้างคุณค่า เติบโตอย่างมั่นคง"*
- การใช้งาน: แสดงในส่วนหัว ส่วนปก Hero Cover และท้ายหน้าเว็บ Footer ควบคู่กับประวัติศาสตร์ 90+ ปี

## 10. เช็กลิสต์ความถูกต้องตามหลัก CI & คอนทราสต์การอ่าน (Checklist & Contrast Rules - CI ข้อ 10)

- [x] **ห้ามใช้สีทอง `#B39B6B` หรือทองอ่อน `#D9CBAA` กับตัวหนังสือขนาดเล็ก (< 14px / `text-xs`) บนพื้นหลังสว่าง** เนื่องจากระดับคอนทราสต์ต่ำเกินไป ทำให้อ่านยากและไม่ผ่านเกณฑ์การเข้าถึง
- [x] **ตัวหนังสือเนื้อหาและขนาดเล็กบนพื้นสว่าง** ต้องใช้สีเข้ม **`#1F1F1F` (Charcoal)** หรือ **`#6B5A3A` (Deep Bronze)** เท่านั้น
- [x] **การใช้งานสีทอง `#B39B6B`**: จำกัดไว้สำหรับเส้นขอบ (Borders), เส้นแบ่ง (Dividers), ไอคอนสำคัญ, ตัวเลขขนาดใหญ่ (Metrics >= 24px) และหัวข้อขนาดใหญ่ (Headings >= 18px)
- [x] **ฟอนต์ถูกต้องตามบริบท**: หัวข้อภาษาไทยใช้ `Kanit`, เนื้อหาภาษาไทยใช้ `Sarabun`, ตัวเลขและหัวข้อหรูหราใช้ `Playfair Display`, ตัวเลขสถิติและรหัสสากลใช้ `Inter`
- [x] **การทดสอบ Static Export**: ตรวจสอบว่า `npm run build` สามารถส่งออกไฟล์สำเร็จโดยไม่มี Error
